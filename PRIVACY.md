# NORA TUNNEL — Privacy Policy

## Local-First

NORA TUNNEL is designed as a local-first Android application.

The application does not require a remote account to manage local tunnel profiles.

## Local Data

Tunnel profiles, routing rules, connection history and application settings are stored locally on the device.

Credentials and sensitive secrets are stored using encrypted Android storage.

## No Hidden Telemetry

NORA TUNNEL does not intentionally include hidden analytics, advertising trackers or remote telemetry.

## Configuration Imports

Imported configurations are processed locally.

Sensitive configuration values must never be written to ordinary logs.

## Diagnostics

Diagnostic reports are privacy-safe.

They must not contain:

- Passwords
- Private keys
- Tokens
- PSKs
- Authentication secrets

## Network Information

Diagnostics may contain general technical information such as:

- Android version
- Application version
- CPU architecture
- VPN state
- Connection state
- Protocol
- Transport
- DNS configuration
- General network type

## User Control

Users can delete locally stored profiles, history and cached application data through the application settings or Android system settings.
